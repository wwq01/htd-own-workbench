# 荒天帝工作台使用说明

## 开发环境启动

1. 确认 Node.js 24 LTS 已安装在 `D:\softwareInstall\nodejs\`。
2. 进入 `backend` 目录执行 `npm install`。
3. 执行 `npm run dev`。
4. 浏览器访问 `http://127.0.0.1:17388/`。

首次运行会自动初始化数据库结构；如使用旧版本数据，请先备份再启动。

服务默认使用 `D:\荒天帝工作台` 作为数据根目录，数据库位于 `data\workbench.db`，自动备份位于 `backups\`。

## 数据备份与恢复

- 在“数据与部署 → 本 APP 数据管理”中可导出 JSON 全量备份。
- 可创建、下载和删除 SQLite 文件备份。
- 导入支持全量覆盖、覆盖同 ID、跳过同 ID 三种模式。
- 清空数据支持按模块分组操作，必须输入“确认清空”。

## 系统设置

“系统设置”页面支持深色/浅色主题、数据路径、自动备份频率和备份保留份数设置。

修改数据路径后需要重启服务生效；应用会在目标路径已有数据库时拒绝覆盖。

## 测试与打包

```powershell
$env:Path = "D:\softwareInstall\nodejs;" + $env:Path
npm test
npm run build:win
```

Windows 打包产物为 `build\荒天帝工作台.exe`，脱离 Node.js 即可运行。本版本交付范围为 Windows，不包含 macOS 构建物。

若打包工具无法下载目标 Node 运行时，可使用已校验的 pkg 缓存后重试；正常情况下直接执行 `npm run build:win` 即可。
