## 三、今日踩坑清单与通用解决方案赋能（经验沉淀）

### 🐛 坑 1：toISOString() 的 UTC 时区陷阱

**症状**：在东八区（或任何非 UTC 时区），`date.toISOString().split('T')[0]` 得到的日期可能与本地日期差一天。例如本地周一 2026-08-10 00:30，`toISOString()` 返回 `2026-08-09T16:30:00.000Z`，切出的日期字符串是 `2026-08-09`（周日）。

**影响范围**：所有「本周/本月/7 天内/明日」日期范围统计全部会多算或少算一天。

**解决方案（写入 Lessons Learned）**：
```javascript
// ❌ 严禁（UTC 时区）
weekStart.toISOString().split('T')[0]

// ✅ 必须使用（本地时区）
import { formatDate } from '../../common/utils/date.js';
formatDate(weekStart);
```

**代码审计建议**：全局搜索 `toISOString`，除了 `healthCheck` 的 `timestamp`（它就是要 ISO 格式的 UTC 时间），其他所有拼接到 SQL where 子句的日期字符串必须是 `formatDate`。

### 🐛 坑 2：HtpModal 组件的 `visible` 属性 + `cancel` 事件名

**症状**：`<htp-modal v-if="xxx" @close="xxx">` 写了但点击按钮后弹窗不出现在 DOM。

**根因**：
1. `visible` 属性默认 false，不传则不渲染（即使 `v-if=true` 了，组件内部还是 `v-if="visible"`）
2. 组件源码 [HtpModal.js](file:///D:\WorkSpace\荒天帝的APP\frontend\js\components\HtpModal.js) 的 emit 定义是 `emits: ['update:visible', 'confirm', 'cancel']`，没有 `close` 事件！关闭按钮调用的是 `handleClose()` → `$emit('cancel')`

**正确写法**：
```html
<htp-modal
  v-if="modalVisible"
  :visible="true"
  :title="formTitle"
  @cancel="modalVisible = false"
  @confirm="submitForm"
>
  ...
</htp-modal>
```

### 🐛 坑 3：Vue 3 `vue.global.prod.js` 的模板语法限制

**症状**：`{{ item?.sub?.field }}` 这种可选链在模板 slot 里静默失败，页面空白但不报错。

**根因**：全局构建版（无打包器）的 Vue 模板编译器只支持子集，不支持 ES2020 optional chaining 和 nullish coalescing。

**解决方案**：把取值逻辑封装在 setup() 的函数中，在模板调用纯函数形式：
```javascript
// setup() 里
function getTagType(item) {
  if (!item || !item.meta) return 'default';
  return item.meta.completed ? 'success' : (item.meta.overdue ? 'danger' : 'info');
}
// 模板里
<htp-tag :type="getTagType(item)">{{ item.name }}</htp-tag>
```

### 🐛 坑 4：浏览器缓存旧 JS + Fetch API 缓存统计数据

**两个层面的缓存问题**：
1. **静态资源缓存**：修改 JS 后刷新页面仍加载旧版本 → `Ctrl + F5` 硬刷新。
2. **Fetch API 级缓存**：即使 Ctrl+F5 也没用，因为 fetch 对相同 URL 的 GET 请求默认命中 HTTP 缓存（浏览器保存了响应体）。尤其统计类接口（stats/statistics）每次调用必须返回最新值，必须在请求配置显式禁用：
```javascript
const config = {
  ...options,
  cache: 'no-store', // ← 必须加
  headers: { ...defaultHeaders, ...options.headers },
};
```

### 🐛 坑 5：Windows PowerShell 执行

1. `curl` 不是 curl 是 Invoke-WebRequest：必须用 `curl.exe`。
2. `&&` 连接命令失败：改用 `;` 分隔或使用 cwd 参数。
3. POST JSON 时引号嵌套地狱：先 `Write` 到临时 `.json` 再 `--data "@路径"`。
4. 涉及写入 `D:\荒天帝工作台\`（数据库、日志）的 Node 脚本，必须用 `dangerouslyDisableSandbox: true`，否则沙箱拦截 `*.db-journal` 和 `*.log`。

### 🐛 坑 6：剪贴板权限 + Document 焦点

**症状**：`navigator.clipboard.writeText(text)` 抛出 `NotAllowedError: Document is not focused`。

**根因**：Clipboard API 需要安全上下文（https 或 localhost）且当前文档必须有焦点。自动化测试（WebView）时用户并未真正点击页面，导致 document 无焦点。

**解决方案**：双保险实现（参照 [copy.js](file:///D:\WorkSpace\荒天帝的APP\frontend\js\utils\copy.js)）
1. 优先尝试 `navigator.clipboard.writeText`（如果成功体验最好）
2. 失败 → 降级创建隐藏 `<textarea>`，`textarea.focus()`（**关键**！先获取焦点），再 `textarea.select()` + `document.execCommand('copy')`
3. 最终 `removeChild` 清理

### 🐛 坑 7：后端启动命令导致修改不生效

**症状**：改了 system.service.js 后调用接口结果不变，怀疑是代码没保存，但实际是 Node 进程缓存了旧 JS。

**根因**：之前用 `npm start`（`node src/server.js`）启动，它**不会自动重载**。而 `package.json` 中 `dev` 脚本是 `node --watch src/server.js`（Node 24 内置 watch 模式，修改文件会自动重启进程）。

**解决**：停止旧进程 → `cd backend && npm run dev`。日志若看到文件变更触发重启，就表示 watch 已启用。

```javascript
import { createXxxSchema, updateXxxSchema } from './xxx.schema.js';
import BusinessError, { ErrorCodes } from '../../common/error.js';

class XxxService {
  async list(filters) { return xxxRepository.findAll(filters); }

    const r = await xxxRepository.findById(id);
    if (!r) throw new BusinessError(ErrorCodes.DB_NOT_FOUND, '记录不存在');

    return xxxRepository.updateById(id, data);
  }
  async remove(id) {
    await this.getById(id);
    return xxxRepository.softDeleteById(id);
  }
}
export default new XxxService();
```

```javascript
    // 列表 & 筛选
    const list = Vue.ref([]);
    const loading = Vue.ref(false);
    const filterStatus = Vue.ref('');
    async function loadList() {
      loading.value = true;
      try {
        const params = {};
        if (filterStatus.value) params.status = filterStatus.value;
        const raw = await htdApi.get('/xxxes', params);
        list.value = Array.isArray(raw) ? raw : (raw.list || []);
      } catch (e) { list.value = []; }
      finally { loading.value = false; }
    }
    Vue.watch(filterStatus, loadList);
    Vue.onMounted(loadList);

    // 新建/编辑弹窗（HtpModal！别忘 :visible 和 @cancel）
    const modalVisible = Vue.ref(false);
    const editing = Vue.ref(null);
    const formTitle = Vue.computed(() => editing.value ? '编辑' : '新建');
    const form = Vue.reactive({ name: '', status: '正常' });
    function openCreate() {
      editing.value = null;
      Object.assign(form, { name: '', status: '正常' });
      modalVisible.value = true;
    }
    function openEdit(r) {
      editing.value = r;
      Object.assign(form, { name: r.name || '', status: r.status || '正常' });
      modalVisible.value = true;
    }
    async function submitForm() {
      const name = (form.name || '').trim();
      if (!name) { showToast('名称不能为空', 'warning'); return; }
      const payload = { name, status: form.status };
      try {
        if (editing.value) await dataStore.updateXxx(editing.value.id, payload);
        else await dataStore.createXxx(payload);
        modalVisible.value = false;
        await loadList();
      } catch (e) { /* toast 已显示 */ }
    }

    // 删除（二次确认！）
    const delConfirm = Vue.ref(null);
    function requestDelete(r) { delConfirm.value = r; }
    async function confirmDelete() {
      if (!delConfirm.value) return;
      try {
        await dataStore.deleteXxx(delConfirm.value.id);
        delConfirm.value = null;
        await loadList();
      } catch (e) { /* toast 已显示 */ }
    }

    return {
      list, loading, filterStatus,
      modalVisible, editing, formTitle, form,
      openCreate, openEdit, submitForm,
      delConfirm, requestDelete, confirmDelete,
    };
  },
  template: `
    <div class="list-page">
      <!-- 筛选 + 新建 -->
      <div class="htp-filter-bar">
        <div class="form-row-2">
          <htp-select v-model="filterStatus" :options="STATUS_OPTIONS" placeholder="全部状态" />
        </div>
        <button class="htp-btn htp-btn--primary htp-btn--sm" @click="openCreate">+ 新建</button>
      </div>

      <!-- 空状态 -->
      <div v-if="list.length === 0 && !loading" style="padding: 40px;">
        <htp-empty text="暂无数据，点击「新建」开始"></htp-empty>
      </div>

      <!-- 列表 -->
      <div class="list-container" v-else>
        <div class="htp-list-item" v-for="r in list" :key="r.id">
          <span>{{ r.name }}</span>
          <div style="display:flex; gap:8px;">
            <button class="htp-btn htp-btn--secondary htp-btn--sm" @click="openEdit(r)">编辑</button>
            <button class="htp-btn htp-btn--danger htp-btn--sm" @click="requestDelete(r)">删除</button>
          </div>
        </div>
      </div>

      <!-- 新建/编辑弹窗（别忘 :visible="true"！） -->
      <htp-modal v-if="modalVisible" :visible="true" :title="formTitle"
                 @cancel="modalVisible = false" @confirm="submitForm">
        <label class="htp-label">名称</label>
        <input class="htp-input" v-model="form.name" placeholder="请输入名称" />
        <!-- 其他表单项 -->
      </htp-modal>

      <!-- 删除确认弹窗 -->
      <htp-modal v-if="delConfirm" :visible="true" title="确认删除"
                 :confirm-text="'确认删除'" :confirm-loading="false"
                 @cancel="delConfirm = null" @confirm="confirmDelete">
        <p>确定要删除「{{ delConfirm.name }}」吗？此操作不可恢复。</p>
      </htp-modal>
    </div>
  `,
};
window.XxxPage = XxxPage;
```

### 4.3 验收的标准流程（经验流程化，提高后续阶段验收效率）

