# 荒天帝工作台 技术选型与文件结构规划（Vue 3 无构建版）

## 一、架构调整总说明

本次调整**完全保留核心产品形态**：纯本地私有化运行、单可执行文件交付、双击自动启动服务并打开浏览器、零外部依赖、全程离线可用。
前端升级为 **Vue 3 无构建本地运行方案**，在不改变「开箱即用、无需安装、无需前端构建工具」使用体验的前提下，实现完整的组件化、响应式开发能力，彻底解决原生 JS 方案耦合度高、扩展难、维护成本高的问题，完美匹配「低耦合、高可扩展、高稳定、强兼容」的核心架构目标。

后端架构保持 Node.js 24 LTS 分层设计不变，与前端通过标准 HTTP 接口解耦，技术栈全栈统一为 JavaScript，降低整体维护成本。

## 四、前端核心架构设计说明

### 4.1 组件化实现方案

采用 **Vue 3 选项式 API + 模板字符串** 的方式定义组件，完全兼容浏览器原生运行，无需编译：

1. 每个组件为独立 JS 文件，通过 `Vue.component` 全局注册，或在页面组件中局部注册
2. 组件模板使用 ES6 模板字符串编写，支持完整的 Vue 指令（`v-if`/`v-for`/`v-model`/`v-on`等）
3. 样式通过 BEM 命名规范隔离，每个组件前缀统一，避免全局样式冲突
4. 组件支持 props 传参、事件派发、插槽等完整能力，和工程化 Vue 项目开发体验完全一致

### 4.2 状态管理设计

1. **全局状态**：通过 Pinia 集中管理，如首页统计数据、当前选中项目、全局备忘列表等，跨模块共享数据，避免重复请求和数据不一致
2. **页面状态**：各业务页面内部的状态由组件自身管理，不污染全局
3. **数据更新机制**：操作数据后统一更新 Store，所有引用该数据的组件自动响应式更新，无需手动操作 DOM

### 4.3 路由实现方案

自研极简 Hash 路由，轻量高效，完全满足当前业务规模：

1. 监听 `hashchange` 事件，根据 URL 哈希值匹配对应页面组件
2. 左侧导航点击修改 hash，触发页面切换，主内容区局部渲染，无整页刷新
3. 支持路由参数传递，如项目 ID、复盘 ID 等，满足跨页面跳转传参需求
4. 预留扩展位，后续功能增多可无缝替换为完整版 Vue Router

### 4.4 样式体系设计

1. **设计令牌统一**：所有颜色、字号、间距、圆角全部通过 CSS 变量定义，和视觉规范一一对应，全局统一修改
2. **样式隔离方案**：采用「模块前缀 + BEM」命名规范，如 `.project-card__title`，从命名层面避免样式冲突
3. **工具类复用**：提供通用 margin、padding、flex 布局等工具类，减少重复样式代码

## 五、前后端协作与交付方式

### 5.1 开发阶段协作

1. 后端提供标准 RESTful API，接口路径统一为 `/api/v1/xxx`，响应格式统一为 `{ code: 0, msg: 'success', data: {} }`
2. 前端通过封装的 `api.js` 统一调用接口，数据和视图自动绑定，开发专注于业务逻辑，无需关心 DOM 操作
3. 后端托管前端静态资源，启动服务后直接访问即可，无需单独启动前端服务

### 5.2 最终交付形态

保持单文件交付体验不变：

1. 打包时，将整个 `frontend` 目录的所有静态资源，通过 Node.js 内嵌方式编译进最终的可执行文件中
2. 用户双击 exe 文件，服务启动，自动唤起默认浏览器打开应用，全程无额外文件、无安装步骤
3. 数据文件自动存放在系统用户目录，和程序本体分离，卸载、升级不丢失数据

## 六、架构核心优势（对应四大核心诉求）

### 6.1 低耦合

- 前端组件化拆分，通用组件与业务页面完全分离，修改通用组件不影响业务逻辑
- 前后端通过接口完全解耦，各自独立迭代，修改后端不影响前端，反之亦然
- 后端严格分层，路由、控制、服务、数据层职责单一，单向依赖，无循环依赖

### 6.2 高可扩展

- 新增业务模块：前端新增页面组件 + 注册路由，后端新增模块目录 + 注册路由，核心代码零修改
- 新增复杂功能：可直接引入本地第三方库（如 Markdown 编辑器、图表库），无缝接入 Vue 体系
- 架构升级平滑：未来可无缝迁移到 Vite 工程化、Electron 桌面端，业务代码复用率 90% 以上

### 6.3 高稳定性

- Vue 响应式系统保障数据与视图一致，杜绝手动 DOM 操作引发的各类渲染 bug
- 后端全局异常捕获，单个接口报错不影响整体服务运行
- 数据库事务 + 自动备份机制，数据安全有多重保障

### 6.4 强兼容性

- 前端兼容所有主流现代浏览器，无私有 API 依赖
- 数据库支持版本化迁移，旧版本数据可无损升级
- 第一版仅交付 **Windows 单平台**产物：打包为单个 `.exe`，脱离 Node 环境双击即运行；本版**不提供 macOS 产物**，也未做安装包（裸 exe）
- 导出的 JSON 备份格式向下兼容，全版本通用
