# 多主题切换规范（V1.4 落地版）

> 配套方案：[V1.4.0-实现方案与代码变更清单.md](./产品迭代/V1.4.0-实现方案与代码变更清单.md) §3 / §4.1
> 本文件是「多套外观切换」的单一事实源，覆盖三维模型、theme.json 字段、CI 校验规则与降级策略。
> 核心原则：**主题仅覆盖 CSS 变量，组件 CSS 零改、class 名契约不变、JS 不动、业务数据零迁移**。

---

## 1. 三维主题模型

主题由 `<html>` 上的三个 `data-*` 属性组合决定，三轴解耦、可独立演化：

| 维度 | 取值 | 落点 | 说明 |
| --- | --- | --- | --- |
| `data-appearance` | `liquid-glass` / `notion-flat` | `<html>`（V1.4 新增） | **外观家族**：表面材质差异（玻璃 vs 平铺），非配色差异 |
| `data-theme` | `dark` / `light` | `<html>`（既有，保留） | **明度模式** |
| `data-decoration` | `on` / `off` | `<html>`（V1.4 新增） | **装饰开关**，仅 `liquid-glass` 生效；`notion-flat` 强制 `off` |

> ADR-v14-01：分轴而非单一 `theme` 枚举，是因为 Liquid Glass 与 Notion 是「表面材质」差异而非「配色」差异；分轴后未来加 Neo-Brutalism 只需新增一个 `appearance` 层，不动明度/装饰轴。

### 1.1 组合矩阵（当前 4 套有效组合）

| appearance | theme | decoration | 语义 |
| --- | --- | --- | --- |
| liquid-glass | dark | on | 默认外观（暗色 + 背景光斑/玻璃） |
| liquid-glass | light | on | 亮色玻璃 |
| liquid-glass | dark/light | off | 关装饰：背景墙实色、无光斑 |
| notion-flat | dark | off（强制） | Notion 极简平铺，暗 |
| notion-flat | light | off（强制） | Notion 极简平铺，亮 |

## 2. 前端主题管理器

`frontend/js/utils/theme-manager.js`（V1.4 新增，app.js 之前最早执行，防 FOUC）：

- `applyTheme(partial)`：仅设置 `<html>` 的 `data-appearance` / `data-theme` / `data-decoration` 三属性；`notion-flat` 自动把 `decoration` 强制为 `off`。
- 双写：`localStorage['htd-theme']` + 服务端 `/system/settings`（下次刷新从 settings 重载，视觉一致）。
- `prefers-reduced-motion` 时动画时长强制归零（与组件 CSS 的 reduced-motion 分支一致）。
- 暴露 `window.htdTheme = { applyTheme, getCurrent }`，供 `SettingsPage` 与命令面板调用。
- 降级：令牌缺失/加载失败 → 回退 Liquid Glass 默认（AC-06）。

入口接线（V1.4 已落地）：`frontend/index.html` 在 `app.js` 之前引入 `theme-manager.js`；`frontend/js/store/appStore.js` 提供 `applyAppearance(partial)`（委托 `window.htdTheme.applyTheme`）与旧 `applyTheme(theme)` 兼容分支。

## 3. CSS 重组策略（零改选择器/类名）

3 个 CSS 文件**选择器与类名契约完全不动**（class 契约 329 不变）：

- `global.css`：`:root` 保留既有值作兜底；新增 `html[data-appearance="notion-flat"]` 覆盖块（把 `--glass-*` 重映射为实色/0、背景墙改实色）+ `html[data-appearance="notion-flat"][data-theme="light"]` 组合块 + `html[data-decoration="off"] body { background-image:none }`。
- `components.css` / `pages.css`：**不改任何选择器/属性值**。组件已引用 `--glass-*` / `--shadow-*` / `--border-*` 等令牌，覆盖层自动令其变平/变实。

> 任何新色值只能出现在 `:root` / 覆盖层 / `theme.json`，组件 CSS 不得裸写 hex（P0 红线，由 `visual-audit.js` 扫描）。

## 4. theme.json 规范字段（CI 校验对象）

ADR-v14-04：内置主题由 CSS 覆盖层提供运行时值，`theme.json` 同时作 **CI 校验对象** 与 **未来自定义主题格式**，避免双源漂移。

每个主题文件顶层必含：`id` / `name` / `version` / `appearance` / `supportsDarkLight` / `dark` / `light`；`dark` 与 `light` 各含：`colorPalette` / `borderRadius` / `shadows` / `typography` / `motion` / `spacing` / `decorations`。

当前两份：`frontend/themes/liquid-glass.theme.json`、`frontend/themes/notion-flat.theme.json`（均 `version: 1.4.0`）。

### 4.1 两套外观差异签名（CI 自动断言）

| 令牌 | Liquid Glass | Notion 极简平铺 |
| --- | --- | --- |
| `--glass-blur` | 22 | 0 |
| `--glass-bg` | 半透明 | 实色 |
| `--glass-border` | 高光描边 | 发丝线 |
| `--glass-highlight` | 有 | transparent |
| `--bg-spot-1/2` | 有色光斑 | transparent |
| `--bg-gradient` | 分层渐变（靛蓝/青，非紫粉） | 实色 |
| `--shadow-card` | 非空 | null |
| `--radius-base` | 12 | 6 |
| `--spacing-base` | 16 | 12 |
| `decorations.glassStyle` | glass | flat |

## 5. 可访问性（WCAG AA）

`fgPrimary/fgSecondary/fgTertiary` 对 `panel/bgPage` 对比度四套均 ≥ 4.5:1（fgTertiary 临界项已收紧取 `#566573` / `#6B6A66`）。主色按钮白字（`#5B8DEF`）对小号文字临界，建议小号/窄屏主按钮文字改用更深主色 `#2456BF` 以保 4.5:1。`validate-theme.js` 会校验对比度。

---

## 6. CI 校验规则（门禁）

`.github/workflows/ci.yml` 的 `lint` job 运行：

- `node scripts/validate-theme.js`：校验 theme.json 顶层 7 字段齐全、暗亮双套存在、圆角 ≤ 28、动效时长 ≤ 400ms、easing 非弹跳、`fg` 对 `panel/bgPage` 对比度 ≥ 4.5:1（WCAG AA）。
- `node scripts/visual-audit.js`：审计令牌完整性（`:root`/覆盖层/`theme.json` 三方一致）、class 名契约（329 不变）、禁项扫描（emoji / 紫粉渐变 / 弹跳缓动 `cubic-bezier(0.68,-0.55,0.265,1.55)` / 组件与页面 CSS 硬编码 hex）、输出 `visual-audit-report.json`。

> 注：`visual-audit.js` 当前扫描 CSS 层；前端 JS 模块中的历史 emoji 债务（见 OPEN-DECISIONS D1）尚未被 CI 自动拦截，全量清除待用户拍板。新增模块已保证零 emoji。

---

## 7. 降级与兼容性

- 主题仅改 `<html>` 属性与 CSS 变量，不触发 DB 迁移、不改业务数据、不改 API 契约（AC-04）。
- 老 `settings.json`（仅 `theme:dark/light`）仍可解析：`settingsUpdateSchema` 仅加 `appearance` / `decoration` 可选枚举，缺省回退默认（AC-07）。
- 令牌缺失/加载失败时回退 Liquid Glass 默认（AC-06）。

## 8. 验收要点（摘要，完整见方案 §8）

- AC-01/02：选择外观+明度即时应用、刷新后持久一致。
- AC-04：仅 CSS 变量变化，业务数据零迁移。

- AC-07：非法枚举经 zod 拒绝（400）。
- AC-26：V1.4 交付代码无新增 emoji / 硬编码色 / 紫粉渐变 / 弹跳缓动。
- AC-27/28（P1）：两套外观 8 页视觉比对 + WCAG AA + 动效 ≤ 300ms，靠 `validate-theme.js` + `visual-audit.js` 守门（亮色锚点帧见 R7，属设计资产，不在代码层强制）。
