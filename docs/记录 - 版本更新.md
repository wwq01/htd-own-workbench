## V1.5.0 — 2026-09-03（数据可视化 + 跨模块搜索 + 字段配置平台 + 阅读模块）

> **基于：V1.4.0 之后**

### 类型
- feat（数据可视化：首页 / 学习 / 财务 / 项目详情图表）
- feat（跨模块搜索：`GET /api/v1/search` + 命令面板搜索分支）
- feat（字段与状态机配置平台：自定义下拉项 / 扩展字段 / 状态机迁移规则，设置页可配置且业务模块即时消费）
- feat（阅读资料模块：4 类型 / 4 态状态机 / 一键转 Vault 沉淀 / 自定义扩展字段）
- perf（`?fields=` 列表字段裁剪，已接入 reading / project / todo）
- test / docs

### 改动点
1. **数据可视化（§8.1）**：后端新增 `system.service.js#getCharts()`（`{home, study, finance}` 三类 11 个数据集）与 `getProjectCharts(projectId)`（里程碑时间线 + 任务速率），对应 `GET /api/v1/system/charts` 与 `GET /api/v1/system/project-charts`。前端新增 `frontend/js/utils/charts.js`，暴露 `window.htdCharts`（`barChart` / `donutChart` / `lineChart` / `stackedBarChart` / `timelineChart` / `legend`），**手写 SVG、无第三方图表库**，配色走 CSS 变量随主题自适应，输出字符串由 `v-html` 注入。挂载于 `HomePage`（4 图）、`StudyPage`（2 图 + 日/周/月周期切换）、`FinancePage`（4 图）、`ProjectPage`（时间线 + 任务速率环）。
2. **跨模块搜索（§8.2）**：新增 `backend/src/modules/search/`（router / controller / service / schema / test），以 `MODULE_CONFIGS` 注册表覆盖 **15 个已注册模块**，按模块分组返回 `{groups:[{module,label,items:[{id,title,snippet,route}]}], total}`。索引策略为 **SQLite `contains`（LIKE）**，离线可用、零外部依赖，**本版未使用 FTS5**。前端 `HtpCommandPalette` 新增搜索分支：250ms 防抖、命令结果在前搜索结果在后统一编址、每组 5 条 + 「查看全部」、结果可跳转模块 route。
3. **字段与状态机配置平台（§8.3）**：新增 `fieldConfig.service.js` / `fieldConfig.schema.js` / `fieldConfig.service.test.js` 与 `backend/src/lib/configSchema.js`。三类配置项（下拉项 `dropdowns` / 扩展字段 `customFields` / 状态机 `stateMachines`）统一以 `SystemSetting` 表固定键存 JSON，以现有枚举为默认种子，未配置时行为不变。配套 `GET/PUT /api/v1/system/field-config`。业务侧通过 `dropdownValue(scope)` / `stateValue(scope)` 取代硬编码 `z.enum`，设置页改完即时生效。阅读模块的类型下拉、状态下拉与状态机迁移表均已接入。
4. **阅读资料模块（§8.4）**：新增 `backend/src/modules/reading/`（router / controller / service / repository / schema + 2 个测试）与 `ReadingMaterial` 模型（表 `reading_materials`，`type` / `readingStatus` 双索引）。支持 4 种类型（文章 / 公众号 / CVE / 论文）与 4 态状态机（unread / reading / precipitated / archived，4×4 穷举矩阵合法 12 / 非法 4），提供 7 个端点，含 `PATCH /:id/status`（过状态机）与 `POST /:id/convert-to-vault`（一键沉淀，**幂等**，经 `vaultService.upsertFromSource` 以 `(sourceType=READING_NOTE, sourceId)` 去重）。自定义扩展字段以 `customFields` JSON 对象字符串存储，前端为自由 key-value 编辑器。
5. **列表字段裁剪（性能优化）**：新增 `backend/src/lib/fieldSelector.js`（`parseFieldsParam` / `pickFields`），列表接口支持 `?fields=id,title` 仅返回指定字段，裁剪发生在 `toPublic()` 之后。已接入 **reading / project / todo** 三个模块。
6. **文档**：新增 `docs/搜索与索引规范.md`、`docs/可视化与图表规范.md`、`docs/阅读模块设计.md` 三份 V1.5 规范（与既有的 `模块挂载点规范.md` / `状态机与字段规范.md` / `多主题切换规范.md` 同层级、同命名风格）。
