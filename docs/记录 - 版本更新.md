## V1.2.0 — 2026-08-16（备份升级 + 命令面板 + 联调打磨）
> **基于：V1.1.0 之后**

### 类型
- feat（备份升级 / 命令面板 / 状态点 / 进程复用）
- refactor（保存三态机 / DataPage 升级 / 启动器）
- test / docs

### 改动点
1. **备份升级（数据安全头牌）**：新增手动备份（可带备注）、每日自动备份（保留 30 份）、恢复前自动生成 `pre-restore` 快照（恢复非破坏性）；恢复前做 SQLite 魔数校验 + `schemaVersion` 版本门 + 路径穿越防护
2. **命令面板（Ctrl/Cmd+K）**：17 条命令（10 跳转 + 4 新建 + 2 切主题 + 1 立即备份），离线手写拼音匹配（中文/全拼/首字母三重）+ 使用频率微调排序
3. **状态点组件（StatusDot）**：4+ 态状态指示（idle/pending/success/error/warning），顶栏实时反映「保存状态」与「备份状态」，支持脉冲动画与 `prefers-reduced-motion` 降级
4. **保存三态机（uiStore）**：`api.js` 统一驱动写类请求，并发写请求用 `_savingDepth` 防闪，成功 2.5s 后回 idle
5. **DataPage 升级**：数据管理页接入备份创建/恢复/列表/状态轮询，备份列表显示类型标签 + 备注，自动暂停红边警告条
6. **启动器进程复用**：启动探测默认端口已有同源实例 → 复用浏览器、不另起进程，避免多进程写 SQLite 锁冲突
7. **基础设施补齐**：新增 `utils/`（observable/motion/fnv1a-hash/draft-state/draft-saver/polling/capability-detector）、`composables/`（useReducedMotion/useSearchParams）、`store/uiStore.js`、中间件 `origin-guard` + `backup-trigger`
8. **版本号**：`appStore.version` 与 `app.config.version` 升至 `1.2.0`

## V1.1.0 — 2026-08-11（视觉重构：Liquid Glass）
> **基于：V1.0.0 之后**

### 类型
- refactor
- docs

### 改动点
1. 全局视觉重构为 **macOS 天气 APP 风格**的 Liquid Glass（液态玻璃）外观
2. 新增 **背景墙分层渐变 + 蓝紫光斑**（暗/亮双版本），让玻璃能透出底色
3. 所有面板 / 卡片 / 按钮 / 输入 / 标签 / 弹窗 / 列表 / 进度 / Tabs / 翻页 / Toast 全部玻璃化（半透明填充 + 背景模糊 + 内高光 + 多层投影 + 1px 高光描边）
4. 圆角统一放大（`--radius-base: 6→12px`、`--radius-md: 16px`、`--radius-lg: 22px`）
5. 强调色由 `#3B82F6` 改为 `#5B8DEF`（暗色）/ `#2F6BEE`（亮色），去网页蓝感
6. 引入 `--glass-bg / --glass-border / --glass-highlight / --glass-blur / --glass-saturate / --glass-fallback` 六个 Liquid Glass 专用令牌
7. 提供 `backdrop-filter` 不支持环境的 `@supports` 实色回退
8. 仅改动 3 个 CSS 文件，业务功能、class 名契约、后端、数据库完全未动
