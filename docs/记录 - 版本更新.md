> 版本号遵循 **语义化版本** `主版本.次版本.修订号`（`MAJOR.MINOR.PATCH`）：
> - `MAJOR` 重大不兼容变更

> - `PATCH` 向后兼容的问题修复 / 局部重构 / 文档更新

## V1.1.0 — 2026-08-11（视觉重构：Liquid Glass）
> **基于：V1.0.0 之后**

### 类型
- refactor
- docs

### 改动点
1. 全局视觉重构为 **macOS 天气 APP 风格**的 Liquid Glass（液态玻璃）外观
2. 新增 **背景墙分层渐变 + 蓝紫光斑**（暗/亮双版本），让玻璃能透出底色
3. 所有面板 / 卡片 / 按钮 / 输入 / 标签 / 弹窗 / 列表 / 进度 / Tabs / 翻页 / Toast 全部玻璃化（半透明填充 + 背景模糊 + 内高光 + 多层投影 + 1px 高光描边）
4. 圆角统一放大（`--radius-base: 6→12px`、`--radius-md: 16px`、`--radius-lg: 22px`）
5. 强调色由 `#3B82F6` 改为 `#5B8DEF`（暗色）/ `#2F6BEE`（亮色），去网页蓝感
6. 引入 `--glass-bg / --glass-border / --glass-highlight / --glass-blur / --glass-saturate / --glass-fallback` 六个 Liquid Glass 专用令牌
7. 提供 `backdrop-filter` 不支持环境的 `@supports` 实色回退
8. 仅改动 3 个 CSS 文件，业务功能、class 名契约、后端、数据库完全未动

### 改动文件
| 文件 | 改动类型 | 说明 |
|---|---|---|
| `frontend/css/global.css` | 修改 | 重映射全部 CSS 变量；新增 6 个 glass 令牌；新增双主题背景墙；新增 Toast 玻璃样式；新增 `@supports` 兜底 |
| `frontend/css/components.css` | 修改 | HtpButton / HtpModal / HtpCard / HtpInput / HtpTextarea / HtpSelect / HtpTag / HtpCheckbox / HtpEmpty / HtpProgress / HtpFilterBar / HtpTabs / HtpListItem 全部玻璃化；统一 focus 外发光 |
| `frontend/css/pages.css` | 修改 | 外壳悬浮分层（侧栏/顶栏/主区之间 16px 间隙）；侧栏激活态玻璃胶囊 + 左侧 2px 主色条；统计卡 / 项目卡 / 复盘卡 / 凭据卡 / 部署卡 / 待办卡 / 娱乐卡 / 复盘自动数据 全部玻璃化；进度条带顶部高光 |
| `backend/package-lock.json` | 修改 | 依赖锁文件随 `npm install` 自动更新 |
| `docs/版本更新记录.md` | 新增 | 本文档（规范化版本变更日志） |
