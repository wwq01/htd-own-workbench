# ADR-001: Sarasa 字体采用「打包 @font-face 随 exe」方案

## Status
Accepted（2026-08-15）

## Background
荒天帝工作台定位为**本地优先 / 离线可用 / 数据自主**的单机 B/S 工具，前端字体需满足：
- 宪法约束：Sarasa Gothic SC 仅含 Regular(400) / Bold(700)，**禁用 Medium(500)**（Sarasa 无 Medium 字重文件）；
- 不能依赖用户系统已装字体（否则换机/干净环境显示降级）；
- 需随 `.exe` 单文件打包分发。

体检报告 §7 原将此列为「待拍板」，需用户在「系统安装」与「打包 @font-face」之间定夺。

## Decision
- **加载方式**：采用「打包 `@font-face` 随 exe」方案，**不**依赖系统安装。
  - 源：GitHub `be5invis/Sarasa-Gothic` v1.0.40，仅提取 Regular + Bold 两 TTF 至 `frontend/fonts/`；
  - `global.css` 顶部两段 `@font-face`（400/700），`local()` 短路 + `../fonts/*.ttf` 兜底 + `font-display: swap`；
  - `pkg.assets` 已含 `"../frontend/**/*"`，字体随 exe 自动打包。
- **Medium 回退**：`--font-weight-medium: 500 → 600`（SemiBold）。因 Sarasa 无 Medium，原 500 会回退伪粗；改为 600 后回退到 Bold(700)，纯令牌改动、CSS class 契约不变。
- **仓库代价**：+46MB（两 TTF），评估为可接受。

## Consequences
- 正面：离线/换机零字体依赖，exe 自带字体；命名契约与宪法一致（仅 Regular/Bold）。
- 负面：仓库体积增大 46MB；`--font-weight-medium` 实际渲染为 Bold（"medium" 显粗体）。
- 备注：若未来需真·中间字重，可额外打包 SemiBold 字重（非 Medium，超出「仅 Regular/Bold」字面），届时另立 ADR。
