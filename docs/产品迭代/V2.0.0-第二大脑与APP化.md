# V2.0.0（远期）— 知识沉淀深化 + 本地 Agent + 可选云 + APP 化
> 基于：V1.5.0之后 | 目标：工作台从"工作生活一体化"演进为"个人第二大脑+本地Agent协作平台+原生APP"。

## 9.0 APP化升级（V2.0标志改动）
详细分析见../分析 - APP化演进.md
关键判断：项目已前后端分离+已用pkg打包（已是"伪APP"）V2.0升级为"真APP"
- 技术选型：Tauri（Rust壳+系统WebView+Node sidecar）
- 目录新增app/src-tauri/：Rust壳代码（200~500行）业务代码0改动
- Node sidecar：Tauri主进程启动Node子进程监听17388前端仍走http://localhost:17388/api/*
- 系统集成：系统托盘/全局快捷键（Cmd+Shift+H唤起）/原生菜单/通知/自动更新
- 打包产物：Windows .msi/.exe + macOS .dmg/.app（V2.0暂不签名）
- 保留pkg打包：V1.x老用户仍可用.exe（Web体验）Tauri设为默认
- 跨平台兼容：明确Windows10+/macOS11+
- 业务API不变：HTTP API形式保持V2.0业务代码0改动
关键决策：不引入Electron（包大10倍）不引入PWA（无法访问本地SQLite）不自写WebView2原生壳（双端代码成本太高）

## 9.1 知识沉淀深化（借鉴person_dashboard）
- Markdown Vault化：沉淀模块升级为完整Vault 支持双向链接/标签树/引用图谱
- 知识图谱：基于标签/引用关系绘制轻量图谱（d3-force/SVG手写）
- 阅读状态机：沉淀条目支持"未读/在读/已沉淀/归档"
- 跨设备Vault：Vault路径外置可由用户指向其他目录
- Note双轨模型（free/quote）（来自../报告 - ReaderWorkspace剖析.md §1）：
  每条沉淀条目都带type='free'|'quote' + anchor（段落索引+偏移+前后文+occurrence）
  实现"笔记↔原文双向跳转"。落地：沉淀条目详情页。预期收益：沉淀不是孤岛能回到来源
- 客户端预览模式（来自ReaderWorkspace§8 + codex协作§7）：
  AI不可用时前端整理"用户已审阅的方案+来源+笔记"→复制到剪贴板→唤起预览框手动复制。落地：沉淀导出/方案分享/POC交接。预期收益：AI不可用也不掉链用户始终是最后一步

## 9.2 本地Agent协作
- Agent通道：在D:\荒天帝工作台\agent-inbox\下投放任务文件本地Agent（如Codex/Claude Code）读取后写回结果
- Skills协议：借鉴person_dashboard的research-social-insights思路把"周复盘生成器"等内化到本地Agent
- 审计日志：所有Agent操作写入logs/agent-actions.log便于回溯
- JobRunner状态机+单一transition()（来自codex协作§1）：
  AGENT_JOB_STATUS 6态 + ALLOWED_TRANSITIONS状态迁移表。所有Agent任务都走这个状态机业务态和进程态解耦
- 依赖注入Runner工厂（codex协作§2）：
  createAgentRunner({spawnImpl, idFactory, now})可测试+可换LLM
- SafeLineStream + Cancellable（codex协作§4-5）：
  10MB字节预算防OOM + SIGTERM/3s后SIGKILL双信号取消
- 三层错误码+BackendError基类（codex协作§6）：检测层/执行层/结果层 前端按code差异化提示
- Capability Detector（codex协作§13）：启动时检测本地有哪些Agent可用 系统设置页加AI能力矩阵
- 纯函数Prompt构造器（codex协作§12）：每个业务场景一个buildXxxPrompt.js 不读文件不调IO可单测可版本化

## 9.3 可选云
- 云端只读备份：用户在系统设置配置云端备份目标（任意WebDAV/S3兼容服务）默认关闭
- 跨设备扫码登录：仅在用户主动开启时启用 登录态保存在本机不上传任何业务数据
- 明确边界：所有"云"特性必须在系统设置中明示开关状态并支持一键关闭

## 9.4 数据安全升级
- 主密码+本地加密：可选AES-256-GCM加密SQLite密钥派生自主密码
- 密码找回方案：基于"加密备份+助记词"的本地找回流程避免数据永久丢失
