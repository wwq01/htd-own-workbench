# V1.4.0 — 视觉多套 + 跨平台启动器 + CI + 资产深化
> 基于：V1.3.0之后 | 目标：让工作台"用得久"——多套外观按需切换、跨平台启动器、工程化基础。

## 7.1 视觉多套（借鉴my-own-app）
- 外观切换器：系统设置新增"外观"选项，至少支持3套：
  - Liquid Glass（现有玻璃化）
  - 极简平铺（Notion风，纯平+紧凑）
  - Neo-Brutalism（强边框+高对比，可选）
- 外观与主题解耦：每套外观支持暗/亮两套
- 切换不迁移数据：仅CSS主题切换，业务数据零变化
- 主题描述文件+规范文档：每套主题按[前端总纲§3.2主题系统架构](./前端系统化设计.md#32-主题系统架构)提供theme.json；新增../视觉规范-多套外观.md ⏳ 待创建 记录每套色板/圆角/阴影/间距/装饰元素
- 总纲基线遵守：所有主题必须满足总纲§2分层架构中L1-L6基线要求（行为契约不绑死视觉）
- 视觉一致性审计：每个外观跑8个核心页面截图比对（脚本scripts/visual-audit.js）
- CI拦截：CI跑scripts/validate-theme.js（theme.json字段+对比度+时长范围）不通过拒绝合并

## 7.2 跨平台启动器（借鉴my-own-app）
- macOS启动器：启动荒天帝工作台.command（chmod +x）等价于Windows .bat
- 端口顺延与复用：检测127.0.0.1:17388占用顺延17389/17390；已运行则复用
- 版本升级时先备份再替换：构建产物变化时保留当前SQLite
- 数据目录可覆盖：通过HTD_DATA_ROOT/HTD_PORT调整

## 7.3 持续集成
- GitHub Actions：lint+typecheck+test+build+启动器测试（macOS+Windows runner）
- 预发布门禁：所有检查通过才允许push/合并

## 7.4 工作/资产深化（4个新模块/能力）
- POC跟踪（工作）：POC目标/环境/客户参与人/结果记录 独立于项目阶段
- 投标档案（工作）：投标编号/截止时间/标书版本/中标结果 里程碑联动
- 漏洞跟踪库（资产或工作）：漏洞编号/影响产品/利用方式/复现/修复状态
- 应急响应记录（工作）：事件时间线/处置动作/复盘 标准化模板
