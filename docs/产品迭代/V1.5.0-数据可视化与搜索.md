# V1.5.0 — 数据可视化 + 全文搜索 + 字段/状态机重构 + 阅读
> 基于：V1.4.0之后 | 目标：让工作台"看得清、找得到、拓得开"。

## 8.1 数据可视化（借鉴my-own-app）
- 首页统计图表：本周完成趋势/项目阶段分布/学习时长趋势/习惯完成率
- 项目详情页：里程碑时间线+任务完成速率
- 学习统计页：日/周/月切换按技术方向分组堆叠柱状图
- 财务统计页：月度收支+分类饼图+合同回款进度
- 图表库选型：优先无构建版兼容方案（SVG手写/UMD版本）避免引入大型库

## 8.2 全文搜索（借鉴person_dashboard MiniSearch）
- 模块内搜索：每个页面顶栏已有的筛选增强为"模糊+字段"搜索
- 跨模块搜索：命令面板K中加入"搜索"分支 搜索范围：待办/项目/任务/片段/凭据/部署/复盘/沉淀/习惯/时间块/财务
- 结果按模块分组：每组5条+"查看全部"
- 索引策略：SQLite FTS5（首选）或Node内置MiniSearch索引

## 8.3 字段/状态机重构
- 自定义下拉：标签、阶段、领域等允许在系统设置里增减（仅本地不联网）
- 自定义字段：模块允许添加"扩展文本字段"（单行/多行）
- 状态机可配置：每个模块的状态机可由系统设置定义迁移规则

## 8.4 阅读/资料（V1.5引入补全知识组输入端）
- 独立模块归属"知识"组
- 字段：标题/来源URL/类型（文章/公众号/CVE/论文）/标签/阅读状态（未读/在读/已沉淀/归档）/笔记（Markdown）
- 导入：粘贴URL自动抓取标题（可选本地解析HTML V1.5仅手动填）
- 沉淀通路：阅读项→Vault条目一键转化
- 测试：状态流转/Vault转化

## 8.5 性能与体积
- 前端按页面分块加载（必要时引入esbuild局部构建）
- 后端接口增加"按字段裁剪"参数（?fields=id,title,status）

## 8.6 文档（搜索与索引规范.md/可视化与图表规范.md/阅读模块设计.md 放docs根/更新版本更新记录）
## 8.7 验收（搜索1w条数据下响应<100ms/图表渲染<16ms/帧/字段裁剪生效接口体量下降≥30%/阅读→沉淀通路测试）
