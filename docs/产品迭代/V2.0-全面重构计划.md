## 4. 前端工程化重构清单（来自前端审计）

### 4.1 无构建瓶颈（D1=硬需求下不可保留）
- **43 个有序 `<script>` 拼装**（`index.html:22-97`），顺序敏感、错序即白屏（约束 C1）
- **全局命名空间污染**：`window.htdApi`/`window.htdIcon`/`window.useDataStore`/`window.__htdApp`/`window.eventBus` 双向紧耦合
- **全量加载无代码分割**：21 模块首屏全下
- **P0-3 图表机制**与 1k 节点验收硬性不兼容
- **无类型安全**（运行时才暴露 undefined）

### 4.2 meta.js 单一数据源（根治 6 处注册漂移）
- 每模块 `meta.js` 声明：`key/name/group/icon(htdIcon key)/route/view/capabilities/homeSummaryCard/commands`
- **S1（无构建）**：新增 `registry.js` 聚合 → 派生 `pageComponents`/`NAV_ITEMS`/`COMMANDS`；新增模块降为 **2 处**（写 meta.js + index.html 加 2 script）
- **S2（Vite）**：`import.meta.glob('./modules/*/meta.ts')` → **0 处手工注册**；`index.html` 收敛为单 `<script type=module src=/src/main.ts>`

### 4.3 组件复用缺口（无构建也可做）
- 新增 `useCrud` 组合式（封装 list/load/create/update/delete+modal+toast）
- 新增 `HtpConfirmDialog`（统一二次确认）、`HtpDataTable`/`HtpListPage`（统一列表骨架/空态/分页）
- 图标收敛为单一 `icons.js` 来源

### 4.4 图表统一方案
- 短期（S1）：建立 `--chart-series-1..N` 语义令牌，页面只传语义 key；收敛三套主蓝（`#5B8DEF/#3B82F6/#3D6EFF`）为单一 `--color-primary`
- 中期（S2）：图表改真实 Vue 组件 + 响应式 SVG/Canvas；d3-force 布局与渲染解耦，1k 节点 ≥30fps(中)/60fps(验)

### 4.5 Vite 迁移里程碑（D1 触发）
| 阶段 | 内容 | 估时 | 出口 |
|---|---|---|---|
| S1 | meta.js 注册表，2 处挂载 | 1-2 周 | 新增模块仅改 meta.js+script；测试绿 |
| S2-1 | Vite+ESM 启动，功能等价 | 1 周 | dist/ 可跑、无白屏、注册 0 手工 |
| S2-2 | 图表/图谱组件化 + d3-force + 性能门槛 | 2 周 | 1k 节点帧率达标 |
> S2 总计约 3-4 周（S1 之后）。**S1 必须先于 S2**（否则在漂移注册点上做 ESM 迁移归因困难）。

## 5. 设计系统重构清单（来自视觉审计，含对 UI 报告误判的纠正）

### 5.1 Token 三层（基础/语义/组件）
- Layer1 基础令牌（`:root` 原始值：`--blue-500:#5B8DEF` 等色阶、间距、圆角、动效）

### 5.3 三蓝收敛 + 图表令牌化
- 三套主蓝（`#5B8DEF/#3B82F6/#3D6EFF`）+ 图表 `#60A5FA` → 单一 `--color-primary`；Logo/勾选/工作组色改引用
- `--color-info:#6366F1`(indigo 味) → 改项目专属蓝；`--shadow-card` 死令牌补定义
- 新增 `--color-primary-shadow-*`（`color-mix` 派生）、`--field-bg/border`、`--chart-series-1..N`

### 5.4 图标单一来源（纠正 UI 报告"合规"误判）
- `icons.js` 为唯一来源；`NAV_ITEMS`、命令面板 `ICON`、模板内联 SVG 全部改为 `htdIcon(key)`
- **emoji 残留清零**（实测清单）：`FinancePage.js:550`/`MeetingPage.js:440`/`DevelopPage.js:400`/`ReviewPage.js:262`/`HabitPage.js:227`/`HomePage.js` 注释

`HtpSwitch` / `HtpSkeleton` / `HtpTable` / `HtpDrawer` / `HtpTooltip` / `HtpMarkdownEditor` / `GraphCanvas|GraphSvg`（知识图谱 Vue 组件）
