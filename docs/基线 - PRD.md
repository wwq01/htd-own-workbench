# 荒天帝工作台 PRD（产品需求文档）

## 文档信息

- 文档版本：V1.1
- 适用版本：第一版（MVP）
- 产品定位：基于本地服务 + 浏览器前端（单机 B/S 架构）运行的个人专属工作生活一体化工作台
- 目标用户：网络安全方向售前工程师（个人自用）
- 核心约束：无登录、无联网、无云后端、无云存储、无手机端；数据保存在本机 SQLite 数据库（由内置 Node 服务访问），全程离线、零外部依赖
- 新增内容：补充完整视觉设计规范，作为前端开发视觉落地依据

***

## 一、产品目标和使用场景

### 1.1 产品目标

打造一款完全私有化、轻量化、高适配性的个人效率工具，围绕网络安全售前工程师的日常工作流，覆盖任务管理、项目推进、技术沉淀、学习复盘、凭据管理等核心场景，同时兼顾生活娱乐管理；所有数据100%本地可控，开箱即用，无需部署和依赖外部服务。

### 1.2 核心使用场景

1. **日常工作管理**：每日规划售前工作、日常事务，跟踪任务完成情况，历史工作可追溯
2. **售前项目全周期管理**：记录客户项目信息、跟进阶段、里程碑节点、任务拆解、核心要点，沉淀项目经验
3. **个人开发与技术沉淀**：管理自用工具/脚本开发进度，存档常用代码片段，记录开发问题与解决方案
4. **学习成长闭环**：记录专业/通用学习内容，统计学习时长，管理待学习资源，定期复盘沉淀方法论
5. **敏感信息统一管理**：安全存放工作中的环境账号、密钥、授权码等凭据，统一管理部署配置信息
6. **生活娱乐管理**：统一管理游戏、影视、书籍等娱乐内容，记录进度与感受

## 二、整体页面框架和导航结构

### 2.1 全局布局框架

采用「左侧固定导航栏 + 顶部全局工具栏 + 右侧主内容区」的经典单页应用布局，所有模块切换无页面刷新。

1. **左侧导航栏（固定，常驻显示）**
   - 顶部：产品名称「荒天帝工作台」
   - 中部：共 10 个一级导航项（9 个 PRD 模块 + 后续新增的「系统设置」页），点击切换对应页面
   - 底部：版本标识、本地数据条目总量简要统计
2. **顶部全局工具栏（右侧内容区顶部）**
   - 当前页面标题
   - 全局快速备忘输入框：任意页面可随手录入备忘，即时保存，无需跳转
   - 全局快捷操作：一键导出全部数据（注：首版顶部工具栏的导出按钮为占位，真实导出入口在「数据与部署 → 本 APP 数据管理」标签页）
3. **右侧主内容区**：各模块的功能页面，支持滚动、弹窗表单、标签页切换等交互

### 2.2 导航菜单结构（一级导航，共 10 个：9 个 PRD 模块 + 系统设置）

1. 首页总览
2. 今日工作/明日计划
3. 项目管理（售前定制）
4. 开发工作
5. 游戏娱乐
6. 充电学习
7. 复盘与沉淀
8. 轻量凭据保险箱
9. 数据与部署
10. 系统设置（PRD 外新增页：外观 / 数据路径 / 备份计划 / 运行端口）

### 2.3 全局通用交互规则

1. **实时自动保存**：所有数据变更（新增、编辑、删除、状态切换、勾选）实时经前端调用本地后端 API 持久化至本地 SQLite 数据库，无需手动点击保存按钮（前端无浏览器本地存储，数据全部落在后端 SQLite 单文件）
2. **表单交互规范**：标准化字段全部采用下拉单选、多选勾选、日期选择器；仅个性化内容需手动输入
3. **高危操作二次确认**：删除单条数据、清空全部数据、导入备份覆盖数据，必须弹出确认弹窗，防止误操作
4. **操作反馈**：新增、编辑、删除、复制等操作完成后，给出轻量文字提示，无强制弹窗打扰
5. **弹窗缓存**：表单弹窗未提交关闭后，临时保留已输入内容，再次打开不丢失
6. **列表交互**：已完成/已归档条目自动下沉至列表底部，视觉上弱化显示

## 三、首页的内容结构

### 3.1 页面定位

全局数据聚合入口，核心信息一眼可见，不做复杂编辑操作，所有详情编辑跳转至对应模块。

### 3.2 页面分区与内容

1. **顶部：今日核心信息区**
   - 当前日期、星期展示
   - 今日高优先级待办卡片：拉取「今日工作」中高优先级事项，展示前5条
   - 即将到期里程碑卡片：拉取「项目管理」中所有项目的里程碑，按截止时间排序，临近到期条目高亮提醒
   - 快速备忘预览卡片：展示最近3条快速备忘，支持直接编辑，全部内容可跳转查看
2. **中部：模块数据统计区**
   - 4个统计卡片：进行中项目数、待解决开发问题数、本周累计学习时长、今日未完成待办数
   - 点击任意卡片直接跳转至对应模块
3. **底部：明日计划预览区**
   - 展示明日计划前5条条目
   - 点击跳转至「今日工作/明日计划」模块的明日计划标签页

### 3.3 交互规则

- 首页仅做数据预览和快捷跳转，不支持新增、编辑核心业务数据
- 所有统计数据实时计算，打开页面自动更新

## 四、每个模块的用途与第一版核心需求

### 4.1 今日工作 / 明日计划

#### 模块用途

管理每日工作与生活待办，支持提前规划次日任务，实现「计划-执行-归档」的每日工作闭环。

#### 核心数据字段

| 字段类型 | 字段内容                                 |
| ---- | ------------------------------------ |
| 选择类  | 事项分类（售前工作/日常事务/生活事项）、优先级（高/中/低）、完成状态 |
| 输入类  | 事项标题、补充备注、预计耗时                       |
| 系统字段 | 创建日期、完成时间                            |

#### 核心操作功能

1. 两个标签页切换：今日工作、明日计划
2. 新增、编辑、删除单条待办
3. 勾选标记完成，已完成条目自动下沉
4. 一键将明日计划全部迁移至今日工作
5. 一键将今日未完成事项迁移至明日计划
6. 按分类、优先级筛选待办
7. 历史日期回看：选择任意历史日期，查看当日待办与完成情况
8. 自动按日期归档每日记录

### 4.2 项目管理（售前定制版）

#### 模块用途

全生命周期管理售前项目，内置售前专属字段，支撑从需求沟通到项目结项的全流程跟进，同时支持任务拆解与进度跟踪。

#### 核心数据字段

| 字段类型 | 字段内容                                                                                      |
| ---- | ----------------------------------------------------------------------------------------- |
| 选择类  | 项目阶段（需求沟通/方案撰写/POC演示/投标答辩/交付跟进/项目结项）、安全领域（传统边界安全/数据安全/等保合规/AI安全/大模型安全/智能体安全/零信任/其他）、项目优先级 |
| 输入类  | 客户名称、项目背景、核心需求、方案版本、联系人信息、项目备忘                                                            |
| 日期类  | 启动时间、预计结项时间、里程碑截止日期                                                                       |
| 子数据  | 里程碑列表（名称+截止日期）、一级任务清单（任务名称+完成状态）                                                          |

#### 核心操作功能

1. 左右分栏布局：左侧项目列表，右侧项目详情
2. 新建、编辑、删除项目
3. 按项目阶段、安全领域、优先级筛选项目
4. 项目内新增、编辑、删除里程碑节点
5. 项目内新增、编辑、删除一级任务，勾选标记完成
6. 自动计算项目整体进度（按任务完成比例）
7. 项目独立备忘区，实时保存
8. 一键生成项目复盘：自动携带项目基础信息跳转至「复盘与沉淀」模块

### 4.3 开发工作

#### 模块用途

管理个人自用工具/脚本的开发进度，沉淀常用代码片段，记录开发问题与解决方案，形成个人技术知识库。

#### 核心数据字段

##### （1）个人开发项目

- 选择类：项目状态（开发中/已完成/搁置）、技术栈标签
- 输入类：项目名称、项目描述、待完成事项列表

##### （2）代码片段库

- 选择类：片段分类
- 输入类：片段名称、代码内容、备注说明

##### （3）问题记录

- 选择类：问题状态（待解决/排查中/已解决）
- 输入类：问题标题、问题现象、排查过程、最终解决方案

#### 核心操作功能

1. 三个标签页切换：个人开发项目、代码片段库、问题记录
2. 各分类下的新增、编辑、删除操作
3. 代码片段支持一键复制到剪贴板
4. 按状态、分类筛选对应内容

### 4.4 游戏娱乐

#### 模块用途

统一管理游戏、影视、书籍等娱乐内容，记录进度与个人评价，平衡工作与生活。

#### 核心数据字段

- 选择类：内容类型（游戏/番剧/剧集/书籍/其他）、状态（想看/在玩/已通关/弃坑）、星级评分
- 输入类：作品名称、进度记录、个人短评

#### 核心操作功能

1. 新增、编辑、删除娱乐条目
2. 按类型、状态筛选内容
3. 星级点选评分

### 4.5 充电学习

#### 模块用途

记录学习内容与时长，管理待学习资源，统计学习投入，形成「待学-学习-沉淀」的成长闭环。

#### 核心数据字段

##### （1）学习记录

- 选择类：学习类型（专业学习/通用学习）、技术方向标签
- 输入类：学习主题、核心笔记、资料来源
- 数字/日期类：学习时长、学习日期

##### （2）待学清单

- 选择类：资源类型标签
- 输入类：资源标题、来源链接、备注说明

#### 核心操作功能

1. 两个标签页切换：学习记录、待学清单
2. 新增、编辑、删除对应条目
3. 自动统计本周、本月累计学习时长
4. 待学清单标记「已学习」后，可一键迁移至学习记录
5. 按学习类型、技术方向筛选记录

### 4.6 复盘与沉淀

#### 模块用途

通过结构化模板引导定期复盘，沉淀售前经验与方法论，避免重复踩坑，实现能力持续成长。

#### 核心数据字段

##### （1）周复盘

- 自动填充字段：本周完成任务数、推进中项目数、本周累计学习时长
- 模板填空字段：本周核心成果亮点、踩坑与不足、沉淀可复用经验、下周改进方向

##### （2）项目复盘

- 自动填充/选择字段：关联项目、客户名称、项目周期、复盘结果（成单/丢单/暂停/持续跟进）
- 模板填空字段：客户核心痛点与关注点、方案/演示加分项、暴露的不足、可复用经验技巧

#### 核心操作功能

1. 两个标签页切换：周复盘、项目复盘
2. 新建、编辑、删除复盘记录
3. 周复盘自动拉取当周量化数据，不可手动修改
4. 支持从项目管理一键生成项目复盘，自动填充基础信息
5. 支持按周次、按项目查看历史复盘记录

### 4.7 轻量凭据保险箱

#### 模块用途

统一存放工作中的敏感凭据信息，默认脱敏展示，快速检索调用，避免零散记录丢失。

#### 核心数据字段

- 选择类：凭据类型（环境账号/平台账号/API密钥/授权码/其他）
- 输入类：凭据名称、账号/密钥内容、使用场景、备注
- 日期类：有效期

#### 核心操作功能

1. 新增、编辑、删除凭据
2. 列表默认脱敏展示密钥内容，点击「显示」查看明文
3. 支持一键复制凭据内容
4. 按类型筛选、关键词搜索凭据
5. 页面显著提示：第一版为明文存储，请勿存放极高敏感信息

### 4.8 数据与部署

#### 模块用途

分为两部分：一是管理工作中的环境部署信息，二是管理本工作台自身的本地数据。

#### 核心数据字段

##### （1）工作部署记录

- 选择类：环境类型（演示环境/测试环境/生产环境/本地环境）、设备类型
- 输入类：环境名称、IP地址、配置参数、部署步骤、常用命令、备注

#### 核心操作功能

1. 两个标签页切换：工作部署记录、本APP数据管理
2. 部署记录的新增、编辑、删除、搜索筛选
3. 本APP数据管理：
   - 展示当前本地（SQLite）数据统计：各模块记录条数、数据库文件大小与路径
   - 一键导出全部数据为本地JSON文件
   - 选择本地JSON文件导入恢复数据
   - 一键清空全部本地数据（高危操作，强制二次确认）

### 4.9 系统设置（PRD 外新增页）

#### 模块用途

集中管理应用自身的运行参数与本地数据策略，覆盖外观、数据存放、备份与端口等基础设置，降低用户对文件系统和启动参数的直接接触。

#### 核心设置项

- 外观：主题相关基础设置（默认深色主题，遵循视觉规范）
- 数据路径：本地数据根目录（默认 `D:\荒天帝工作台`，可通过环境变量 `HTD_DATA_ROOT` 覆盖）
- 备份计划：启动自动备份开关、备份保留份数（默认保留最近 7 份）
- 运行端口：本地服务监听端口（默认 17388，被占用自动顺延，可用 `HTD_PORT` 覆盖）

#### 核心操作功能

1. 查看并保存上述设置项
2. 设置变更后由内置 Node 服务读取生效（部分需重启服务）
3. 与「数据与部署」页共享同一套本地数据管理底座

> 注：本页为后续迭代中新增，不在原始 PRD 九大模块范围内，但已随第一版一并交付。

## 五、首页、今日计划和各模块之间的关系

### 5.1 首页与各模块的聚合关系

首页是全局数据的「展示窗口」，本身不产生独立数据，所有内容均来自其他模块：

- 今日高优先级待办 → 来源：今日工作/明日计划
- 即将到期里程碑 → 来源：项目管理
- 快速备忘 → 来源：全局备忘数据
- 模块统计数据 → 来源：项目管理、开发工作、充电学习、今日工作
- 明日计划预览 → 来源：今日工作/明日计划

### 5.2 跨模块核心联动场景

1. **项目管理 → 复盘与沉淀**：项目详情页点击「生成项目复盘」，自动携带项目基础信息，跳转至复盘模块并预填充表单
2. **今日工作 → 明日计划**：支持双向迁移，未完成事项可移至次日，次日计划可移至当日
3. **充电学习-待学清单 → 学习记录**：待学条目标记完成后，可一键转为学习记录，自动携带基础信息
4. **全局快速备忘 → 首页**：任意页面录入的备忘，实时同步至首页预览区

## 六、本地数据文件、备份和恢复的要求

### 6.1 存储方式与原则

<br />

1. 存储原则：所有数据保存在本机 SQLite 数据库文件（`D:\荒天帝工作台\data\workbench.db`），由内置的本地 Node.js 服务读写，不上传、不联网、不同步至任何服务器
2. 持久化要求：刷新页面、关闭浏览器、重启电脑、甚至重装应用（数据目录独立）后，数据均完整保留，不丢失

### 6.2 数据格式

1. 内部存储：SQLite 关系型数据库（Prisma ORM 管理），按业务表分集合存储，支持事务与软删除
2. 导出文件：标准JSON文件，文件名默认格式：`荒天帝工作台备份_YYYYMMDD.json`

### 6.3 数据备份（导出）

1. 触发方式：在「数据与部署 → 本 APP 数据管理」标签页点击「导出全部数据」（注：首版顶部工具栏的同名按钮为占位，真实导出入口仅在此处）
2. 行为：经后端读取全量本地数据，生成标准JSON文件，自动下载到用户电脑默认下载目录
3. 要求：导出文件可直接查看、编辑，无加密、无特殊格式

### 6.4 数据恢复（导入）

1. 触发方式：手动选择本地JSON备份文件
2. 校验逻辑：先校验文件格式合法性，格式错误给出提示
3. 确认逻辑：校验通过后弹出二次确认，告知用户将覆盖当前全部数据
4. 行为：确认后用备份文件数据覆盖本地（SQLite）数据，完成后自动刷新页面数据

### 6.5 数据清空

1. 触发方式：手动点击「清空全部数据」
2. 二次确认：必须弹出强提示，要求用户二次确认，防止误操作
3. 行为：清除所有本应用相关数据（SQLite 中所有表记录），页面恢复初始空白状态

## 七、第一版必须完成的功能

1. 全局布局与 10 个页面（9 个 PRD 模块 + 系统设置）的完整开发

## 九、后续开发需要注意的事项

1. **数据安全优先**：后续新增加密功能时，需确保加密逻辑纯本地运行，密钥不上传；同时做好密码找回方案，避免密码遗忘导致数据永久丢失
2. **扩展性设计**：代码架构需支持新增模块、新增字段，降低后续迭代成本；下拉选项、标签体系预留自定义扩展能力
3. **离线可用性**：始终保持纯离线可用的核心特性，新增功能不得强制依赖网络
4. **兼容性**：优先保证主流桌面浏览器（Chrome、Edge）的兼容性，第一版无需兼容老旧浏览器
5. **数据迁移**：后续版本升级时，必须兼容旧版数据格式，提供自动迁移能力，避免用户数据丢失
6. **AI能力预留**：后续若加入本地大模型能力，需基于本地运行的模型方案，不调用外部AI接口
7. **视觉扩展**：CSS变量定义颜色、圆角、间距等属性，后续加浅色主题、自定义主题时无需重构

## 十一、视觉设计规范

### 11.1 整体视觉风格定位

#### 核心调性

**沉稳专业 · 高效极简 · 科技护眼 · 低干扰度**

- 贴合网络安全行业属性：偏冷色调、强秩序感、可靠厚重
- 适配长时办公：深色基底降低视觉疲劳，对比度适中不刺眼
- 平衡专属命名：仅在品牌标识、产品名上体现「力量感」，不做动漫化/中二化设计，工作场景下使用不违和
- 轻量化落地：无复杂插画、渐变、光影特效，前端可快速实现，不影响运行性能

#### 设计核心原则

1. **效率优先**：视觉服务于信息识别，状态、分类、优先级一眼可辨
2. **层级清晰**：通过背景深浅、边框、微弱阴影区分页面层级，不依赖强色彩
3. **克制点缀**：仅在关键操作、核心数据上用强调色突出，全局色彩不超过3种主色系
4. **统一规范**：所有组件、间距、字号遵循统一栅格与尺寸规则，视觉整齐利落

### 11.2 色彩体系（深色模式为默认/唯一主题）

#### 1. 背景分层色（从深到浅，构建页面层级）

| 层级        | 色值参考      | 使用场景                  |
| --------- | --------- | --------------------- |
| 最深层       | `#0B1220` | 左侧导航栏、顶部全局栏，锚定页面框架    |
| 页面底色      | `#0F172A` | 主内容区背景，整体基底           |
| 卡片/弹窗     | `#1E293B` | 内容卡片、表单弹窗、输入框背景，突出内容块 |
| 悬浮/hover层 | `#273449` | 列表hover、按钮hover、选中态背景 |

#### 2. 文字色（四级文字，保证阅读层次感）

| 层级    | 色值参考      | 使用场景                  |
| ----- | --------- | --------------------- |
| 一级文字  | `#F1F5F9` | 页面标题、核心数据、条目主标题，最高对比度 |
| 二级文字  | `#94A3B8` | 正文内容、辅助说明、普通标签，主要阅读文字 |
| 三级文字  | `#64748B` | 备注信息、时间、次要说明，弱化非核心信息  |
| 禁用/失效 | `#475569` | 不可点击状态、已归档内容          |

#### 3. 品牌/强调色（全局唯一主操作色）

- **主强调色**：`#3B82F6`（沉稳科技蓝）
  - 使用场景：主按钮、选中态、核心数据数字、导航激活态、图标高亮、进度条
- 辅助渐变：仅在产品logo、首页标题处使用极淡的蓝紫渐变，增加专属质感，不大面积使用

#### 4. 功能状态色（统一语义，快速识别）

| 语义    | 色值参考      | 使用场景                |
| ----- | --------- | ------------------- |
| 成功/完成 | `#10B981` | 已完成状态、成功提示、已结项项目    |
| 警告/临近 | `#F59E0B` | 即将到期里程碑、高优先级提醒、警告提示 |
| 危险/删除 | `#EF4444` | 删除按钮、高危操作、错误提示      |
| 信息/常规 | `#6366F1` | 中性标签、提示信息           |

#### 5. 标签专属色（售前场景定制，快速区分状态）

针对项目阶段、任务分类等高频筛选场景，配套固定标签色，形成视觉记忆：

- 需求沟通：灰色标签 `#64748B`
- 方案撰写：蓝色标签 `#3B82F6`
- POC演示：紫色标签 `#8B5CF6`
- 投标答辩：橙色标签 `#F97316`
- 交付跟进：青色标签 `#06B6D4`
- 项目结项：绿色标签 `#10B981`

### 11.3 字体与排版规范

#### 1. 字体选择

优先使用系统原生无衬线字体，保证渲染清晰、加载零成本（第一版以 Windows 为主，字体栈同时兼容 macOS 等主流系统）：

- 优先：`Inter, -apple-system, BlinkMacSystemFont`
- 兼容：`"Microsoft YaHei", "PingFang SC", sans-serif`

#### 2. 字号层级（桌面端适配，基于14px基准）

| 字号   | 字重  | 使用场景                 |
| ---- | --- | -------------------- |
| 24px | 600 | 首页大数字统计、页面大标题        |
| 18px | 600 | 模块页面标题、卡片主标题         |
| 16px | 500 | 二级标题、弹窗标题            |
| 14px | 400 | 正文内容、列表条目、普通按钮（基准字号） |
| 12px | 400 | 辅助文字、时间、标签、备注说明      |

#### 3. 排版规则

- 行高：正文1.5倍，标题1.2倍，保证长文本阅读舒适度
- 字间距：默认即可，不做紧缩或加宽
- 对齐：所有列表、表单、卡片统一左对齐，数据数字右对齐

### 11.4 核心组件视觉规范

所有组件统一圆角、边框、交互态，保证全局视觉一致，采用「微圆角+细边框+弱阴影」的组合，兼顾科技感与轻量化。

#### 1. 通用规则

- 圆角：卡片/弹窗/按钮/输入框统一使用 `6px` 小圆角，利落不圆润，符合专业调性
- 边框：默认 `1px` 实边，色值 `#334155`；hover/选中时边框变为强调色
- 阴影：仅弹窗、下拉菜单使用微弱阴影 `0 4px 12px rgba(0,0,0,0.3)`，普通卡片无边影，靠背景色分层

#### 2. 按钮

- 主按钮：强调色填充+白色文字，hover时颜色加深10%
- 次按钮：透明背景+边框+二级文字色，hover时背景变为悬浮层色
- 危险按钮：红色填充/红色边框，仅删除等高危操作使用
- 文字按钮：无背景无边框，hover时文字变强调色

#### 3. 输入框/下拉选择器

- 常态：浅灰背景+细边框
- 聚焦：边框变强调色，无外发光（避免刺眼）
- 禁用：背景加深，文字变灰

#### 4. 卡片

- 统一内边距：上下16px，左右20px
- 卡片间距：横向16px，纵向16px（遵循8px栅格）
- 卡片内模块分隔：用细边框或间距区分，不做多余分割线

#### 5. 列表

- 行高：40px，上下内边距10px
- 分隔：用极细边框或间距分隔，不做粗分割线
- 选中/hover：背景变为悬浮层色，左侧加2px强调色竖条，视觉反馈明确

### 11.5 布局与空间栅格

全局遵循 **8px 栅格系统**，所有间距、尺寸均为8的倍数，保证页面整齐有序：

- 基础间距单位：8px
- 常用间距：8px / 12px / 16px / 20px / 24px / 32px
- 侧边栏宽度：固定240px（第一版固定宽度，折叠功能后续迭代）
- 顶部栏高度：固定56px
- 主内容区左右内边距：24px，上下内边距：20px
- 最大内容宽度：不限，自适应浏览器宽度，适配大屏显示器

### 11.6 图标与专属标识设计

#### 1. 功能图标

- 风格：统一线性图标，2px线条，圆角端点，简洁无装饰
- 尺寸：导航图标20x20px，操作图标16x16px
- 颜色：默认二级文字色，选中/hover变为强调色
- 来源：使用开源图标库（如Heroicons、Lucide），风格统一且零成本

#### 2. 产品专属标识

不做具象的动漫/人物形象，仅用极简抽象符号体现专属感，兼顾工作场景专业性：

- 产品Logo：极简线性「盾形+山峰」组合符号——盾对应网络安全属性，山峰对应「荒天」的厚重感，颜色用主强调色
- 产品名称：加粗无衬线字体呈现「荒天帝工作台」，字号18px，字重600，放置于侧边栏顶部

### 11.7 动效规范

全程克制动效，仅做「状态反馈类」动效，时长控制在150-200ms，快进快出，不拖慢操作节奏：

1. 按钮/列表hover：背景色平滑过渡
2. 弹窗/下拉菜单：淡入+轻微缩放，快速出现
3. 页面切换：轻微淡入淡出，无滑动动画
4. 勾选完成：图标颜色渐变，无弹跳等夸张动效
5. 禁止：页面入场动画、装饰性动画、悬浮特效等一切干扰专注的动效

### 11.8 第一版视觉落地建议

1. **优先保证可用性**：不用追求像素级还原，先按规范实现基础视觉，保证全局统一、信息清晰
2. **重点打磨3个页面**：首页总览、项目管理、今日工作，这三个是最高频页面，视觉优先级最高
3. **复用组件样式**：所有按钮、输入框、卡片、标签统一样式类，减少开发量，后续迭代方便调整
4. **CSS变量实现**：颜色、圆角、间距等属性统一用CSS变量定义，预留主题扩展能力
